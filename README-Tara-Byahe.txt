TARA BYAHE WEBSITE

Files:
- index.html: website structure and content
- styles.css: responsive design and styling
- script.js: mobile navigation, tour selection, destination expansion, booking request summary, and gallery lightbox

How to run:
1. Keep index.html, styles.css, script.js, and all your original image/video files in the same folder.
2. Open index.html in a browser. For best testing, use VS Code with the Live Server extension.
3. Check that filenames and capitalization of image/video files match those referenced in index.html and styles.css.

Important:
The booking form currently validates fields and shows a request summary in the browser. It does NOT send email, store bookings, take payments, or confirm reservations. To accept real bookings, connect it to a backend/form service and add the agency's verified contact details. Social links are generic placeholders and should be replaced with official profile URLs.
